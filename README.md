# ComfyUI H3 自动导演 (MiniMax H3 Auto Director)

专为 **MiniMax H3** 打造的多片段连贯视频生成、多模态参考管理、双阶段采样与自动排版拼接解决方案。

---

## 🌟 核心特性亮点

- 🎬 **多片段连续生成 & 动作声音自然接续**：基于两阶段独立 AV Latent 上下文接续（一采接一采、二采接二采），消除拼接跳跃感。
- ⚡ **统一参考集潜空间零耗时复用**：开启「统一参考集」后，参考素材仅在第 1 段执行 VAE 编码，后续所有片段 **0 毫秒直接复用潜空间缓存**，显著降低多段生成的显存峰值并大幅节省时间。
- 🛡️ **智能防覆盖与上下文缺失诊断**：
  - 输出目录自动按批次建立隔离文件夹（如 `clips/H3/`、`clips/H3_1/`），最终视频同名自动递增编号；
  - 缺失前序潜空间缓存时，前端自动**模态弹窗报警**，提供「**↺ 一键重置片段序号为 0**」按钮及清晰排查指南。
- 🚀 **全面接入官方 Block Sparse Attention**：已接入 ComfyUI 官方原生最新的稀疏注意力加速方案，在保持顶级画质的同时获得更低的显存占用与更快的采样速度。
- 🎞️ **硬件级音视频解码与多格式封装**：批量解码节点支持 **CPU / GPU (NVENC/QSV/AMF)** 硬件加速编码，支持 `mp4`、`mkv`、`mov`、`webm` 封装及多种编码器（`libx264`, `libx265`, `h264_nvenc`, `hevc_nvenc`, `prores` 等）。
- 📝 **可视化多段剧本编辑器**：支持片段独立提示词/时长、关键帧插入引导、JSON 剧本导入（支持「仅替换提示词」保留配置）及纯文本免素材预编码加速。

## 📦 安装与环境要求

> [!IMPORTANT]
> **必须搭配最新版本的 ComfyUI 使用（建议更新至最新 master 分支或 >= v0.34.0）**。  
> 自动导演工作流已升级集成 ComfyUI 官方最新的 `Block Sparse Attention`（块稀疏注意力）与 `ModelAttentionBackend` 节点。旧版 ComfyUI 因缺少这些官方核心组件将无法正常加载或运行。

### 安装步骤

1. 克隆或解压至 ComfyUI 插件目录：
   ```bash
   cd ComfyUI/custom_nodes
   git clone https://github.com/kongbai-0421/ComfyUI-H3-Auto-Director.git
   ```
2. 重启 ComfyUI。
3. 确保运行环境包含以下基础支持：
   - ComfyUI 原生 MiniMax H3 核心节点、H3 视频/音频 VAE；
   - 视频处理推荐安装 `ComfyUI-VideoHelperSuite`；
   - 音频加载需当前 ComfyUI 的音频节点支持。

## 🚀 快速上手 (Quick Start)

1. **加载工作流**：在 ComfyUI 中打开 `example_workflows/MiniMax H3 Auto Director.json`。
2. **配置项目计划**：
   - 在 `H3 自动导演｜项目计划` 节点中点击「打开项目编辑器」；
   - 配置工程名称、统一输出文件名，在可视化界面中添加/编辑分段提示词、时长及参考素材；
   - 勾选 `统一参考集`（多段共享首段参考素材）或设置 `不编码参考素材`（纯文本极速生成）。
3. **开始连续生成**：
   - 确保 `H3 自动导演｜片段解析` 节点的片段序号为 `0`（从第 1 段开始）；
   - 点击 ComfyUI 的 **Queue Prompt**，插件将自动按序连续生成各片段，并在最后一段完成后自动拼接输出最终视频。

## 🧩 核心节点分类与功能索引

### 1. 项目计划与剧本调度
| 节点名称 | 功能说明 |
| :--- | :--- |
| **`H3 自动导演｜项目计划`** | 核心调度入口。保存片段剧本、时长、参考素材、连续生成开关、统一输出文件名、防覆盖及缓存模式。 |
| **`H3 自动导演｜片段设置`** | 解析当前目标片段参数，提供前置缺失预警与界面尺寸记忆；附带 `↺ 重置为第 1 段` 快捷按钮。 |
| **`H3 自动导演｜多模态素材解析`** | 将项目中的图片、视频、音频参考素材解析为下游可消费的数据结构。 |

### 2. 提示词与潜空间缓存
| 节点名称 | 功能说明 |
| :--- | :--- |
| **`H3 自动导演｜提示词与素材缓存`** | 将多模态素材预先编码为 VAE 潜空间，并执行 CLIP 文本编码。**支持统一参考集潜空间缓存复用**（后续段 0 毫秒跳过重复 VAE 编码）。支持文本向量磁盘持久化。 |
| **`H3 自动导演｜双采样分辨率`** | 输出两阶段对齐的尺寸和分辨率配置。 |

### 3. 上下文接续与双阶段采样
| 节点名称 | 功能说明 |
| :--- | :--- |
| **`H3 自动导演｜上下文读取`** | 读取上一片段生成的潜空间/视频/音频上下文；提供独立的一采与二采上下文输出端口；若潜空间缺失则触发前端弹窗。 |
| **`H3 自动导演｜双阶段采样`** | 执行 MiniMax H3 采样。支持一采与二采独立上下文接续；支持二采跳过或复用一采模型。 |
| **`H3 自动导演｜运动上下文`** | 专为 H3 优化的潜空间直取接续节点。 |
| **`H3 自动导演｜音频采样切换`** | 提供 H3 音频采样方法与基础 Sigmas 调度（优先推荐 `ComfyUI v0.31.0版本方法`）。 |
| **`H3 自动导演｜一采/二采模型加载`** | 选择加载 H3 模型，支持 FL2VA / Ref2VA 混合加载。 |

### 4. 解码、保存与最终组装
| 节点名称 | 功能说明 |
| :--- | :--- |
| **`H3 自动导演｜AV 解码`** | 将 MiniMax H3 联合 AV Latent 解码为图像序列与音频波形。 |
| **`H3 自动导演｜保存片段`** | 逐段写入片段视频、音频和接续用的潜空间缓存；支持子批次嵌套防覆盖隔离。 |
| **`H3 自动导演｜拼接最终视频`** | 在全部片段生成完成后，从磁盘按序读取片段组装最终视频，支持同名递增编号防覆盖。 |
| **`H3 解码｜目录批量解码并保存视频`** | 离线工具节点。可扫描项目目录或 cache 文件夹批量解码 AV Latent，支持 CPU/GPU 硬件编码器与多种格式。 |

### 5. 实验性模块 (TTS / 动作迁移)
- **`H3 自动导演｜TTS 项目计划` / `H3 TTS｜仅解码音频` / `H3 TTS｜拼接最终音频`**：专注于纯音频分段合成与拼接；
- **`H3 自动导演｜动作迁移项目计划` / `H3 视频迁移｜按策略解码`**：按参考视频动作切分片段迁移；
- **`H3 动作迁移｜VideoX-Fun Union 专用采样`**：接入外部 VideoX-Fun 框架的实验性 ControlNet 骨架/深度引导管线。

## ⚙️ 关键技术机制详解

### 1. 统一参考集潜空间缓存复用机制
当项目计划中开启 `global_reference_set = True`（统一参考集）时：
- **首段编码持久化**：第 1 段运行提示词与素材缓存节点时，参考图片、视频、音频通过 VAE 编码后，潜空间结构（`ref_blocks`）被存入全局内存缓存池；
- **后续段 0 毫秒复用**：第 2 ~ N 段处理相同素材时直接命中缓存，**完全跳过极度耗时的 VAE 重复编码**；生成画布的空潜空间（`_empty_av_latent`）按各段独立时长动态构建；
- **动态增量合成**：若某段勾选了「使用上片段视频作为参考」，系统仅对上一段新生成的视频做增量 VAE 编码，原有的全局静态素材依然复用缓存；
- **零脏缓存**：文件缓存键与素材大小、修改时间戳（`mtime_ns`）绑定，磁盘文件一旦被替换或修改，缓存自动失效并重新编码。

### 2. 输出目录层级与防覆盖隔离
生成的项目文件统一保存在 `ComfyUI/output/h3_project/<项目名>/` 目录下：
- 当开启防覆盖（`overwrite_existing = False`）时，每次新批次会在 `clips/`、`cache/`、`context/` 下自动创建隔离子文件夹（如 `clips/H3/`、`clips/H3_1/`、`clips/H3_2/` 等），避免不同批次之间的片段与缓存相互混淆；
- 最终视频保存在 `final/` 目录下，遇到同名视频自动追加递增序号（如 `final/H3_1.mp4`）。

### 3. 统一解码模式 (Unified Decoding)
- 在项目计划中开启「所有片段完成后统一解码」后，采样阶段不做即时 VAE 解码，所有片段完成后由拼接节点逐段从磁盘读取 AV latent 分段解码并组装；
- 能够有效规避长视频一次性大批次 VAE 解码导致的显存溢出（OOM），且彻底解决音画漂移与丢帧问题。

## ❓ 常见问题与排查 (FAQ)

### Q1: 报错 `Missing Stage 1 context latent for segment X`？
- **原因**：上一轮任务生成完成后，画布上的片段序号停留在最后一段（如第 12 段）。清空目录或开始新工程后直接运行，节点会尝试接续不存在的第 11 段。
- **解决方法**：
  1. 插件会自动在前端弹出排查对话框，直接点击弹窗中的「**↺ 一键重置片段序号为 0 并关闭**」按钮即可；
  2. 或在 `H3 自动导演｜片段解析` 节点上点击「重置为第 1 段」按钮，将片段序号恢复为 `0` 后重新运行。

### Q2: 提示词预编码或 VAE 解码时终端长时间没有日志输出？
- **原因**：系统标准输出缓冲区导致输出不及时。
- **现状**：最新版本已全面集成实时流刷新机制（Flush），所有素材预编码与解码进度均会实时前置打印。

### Q3: 加载工作流时提示缺少 `BlockSparseAttention` 或报错？
- **原因**：ComfyUI 版本过旧。
- **解决方法**：请使用 ComfyUI 内置更新器或运行 `git pull` 将 ComfyUI 更新至最新版（>= v0.34.0 或 master 分支）。

### Q4: 报 `Output file does not contain any stream` 错误？
- **原因**：参考视频中没有音频流或音轨损坏。
- **解决方法**：插件会自动跳过损坏音轨并保留画面；若需音频驱动，请使用包含有效音轨的素材。
